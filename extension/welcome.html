Welcome to Media Catcher

The extension needs a small helper app on your computer to do the downloading. You install it once.

The helper app only supports Windows for now.
The download link is not set yet. Edit installerUrl in config.js.
1

Download the helper app

If your browser warns that the file is “not commonly downloaded”, choose Keep.

The download has started. You will find the file in your browser’s downloads.

2

Run the file you downloaded

Windows may show Windows protected your PC because the app is not code-signed. Click More info, then Run anyway.

Keep “Start Media Catcher when I sign in to Windows” checked, then finish the setup.

3

Wait for the tray icon near the clock

The status below switches automatically once the app is running. The icon may be hidden under the ^ arrow.

Waiting for the app...
4

You’re ready

Open a page with a video, play it for a few seconds, then click the extension icon and pick the quality.

To reach it easily: click the puzzle icon 🧩 in the browser, then the pin 📌 next to Media Catcher.

Everything is downloaded on your own computer. If nothing shows up after installing, start Media Catcher from the Start menu.
